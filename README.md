# Crave Online Food Ordering System

Crave is a responsive, front-end-only food ordering demonstration created as a student project. The menu, listed prices, and delivery estimate are sample data for interface demonstration; they do not describe a live restaurant or service.

## Run

Open `index.html` in a modern browser. No build step or package installation is required. An internet connection is needed for the Google Fonts and Unsplash food photographs; the interface and ordering logic run locally in the browser.

## Implemented

- Responsive menu cards, category filters, and text search
- Basket quantity controls and subtotal, sample delivery estimate, and total
- Required name, 10-digit phone, and address validation
- Simulated order confirmation, with no network submission or payment
- Accessible labels, status messages, keyboard-operable buttons, and reduced-motion support

## Limitations

There is no backend, account system, persistent basket, inventory, real restaurant, delivery integration, or payment processing. The demo order exists only in the current page session. Prices and delivery fee are illustrative. Food photography is loaded from Unsplash URLs.

## Proposed future work

If developed beyond the demo: connect a secure backend, store menu and order data, add authentication and order tracking, integrate a compliant payment provider, and conduct accessibility and security reviews. These are proposals, not implemented features.
